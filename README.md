# Karabiner-Elements Configs

A collection of reusable [Karabiner-Elements](https://karabiner-elements.pqrs.org/) configurations for making non-Apple keyboards behave better on macOS.

Each keyboard gets its own folder with a setup guide and, where applicable, a ready-to-use complex modification JSON file.

## Keyboards

| Keyboard | Guide | Highlights |
| --- | --- | --- |
| Rapoo E9050L | [Rapoo-E9050L/SetupGuide.md](Rapoo-E9050L/SetupGuide.md) | Software Fn-Lock toggle (`Left Option + Esc`), Right Control remapped to Right Option |

More keyboards will be added here as new configurations are created.

## Usage

Each guide is self-contained and walks through:

1. Installing Karabiner-Elements and granting macOS permissions
2. Putting the keyboard into the correct mode
3. Copying the provided `complex_modifications` JSON into `~/.config/karabiner/assets/complex_modifications/`
4. Enabling the rule in Karabiner-Elements

See the individual keyboard folder for exact steps.
